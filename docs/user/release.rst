Release notes
-------------

* **0.6.2:** simpler case guides and explicit checkpoint-download instructions.
* **0.6.1:** shorter reference documentation; no analysis changes.
* **0.6.0:** optional local teacher extraction, experimental user-trained students
  and task-fidelity evaluation. See :doc:`distillation` and :doc:`scoped-student`.

Install from source as described in :doc:`installation`. No PyPI release is
currently provided; pretrained weights and processed study datasets are separate.
